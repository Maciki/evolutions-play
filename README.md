# Evolutions — เล่นบนเว็บ

เวอร์ชันเว็บของเกม **Evolutions** เกมแอ็กชัน 3D pixel art ที่สร้างด้วย Godot 4 กินตัวที่เล็กกว่า หนีตัวที่ใหญ่กว่า แล้ววิวัฒนาการผ่าน 10 ขั้น 4 สายวิวัฒนาการ จนไปสู้บอสสุดท้าย

repo นี้เก็บเฉพาะไฟล์เกมที่ build แล้วสำหรับ GitHub Pages ส่วนซอร์สโค้ดอยู่ใน repo แยกต่างหาก

**การควบคุม:** WASD เดิน · กัดอัตโนมัติเมื่อเข้าใกล้ · Q E R ใช้สกิล · Esc หยุดเกม
(บนมือถือ: ลากนิ้วที่ครึ่งจอซ้ายเพื่อเดิน แล้วกดปุ่มสกิลบนจอ)
